# Writing

Never use the middle dot (U+00B7) or the em dash (U+2014) in text you author for this project, including replies, interface copy, documentation, and comments. Use spacing between controls and normal sentence punctuation in prose.

Write comments in plain language. Explain decisions, constraints, and surprising behavior.

Add explanatory sections in UI only when the user explicitly requests them.

# Web

Follow the [web architecture and design standards](docs/web-standards.md) when changing the web app.
